# 第二阶段：注册、优选与六小时缓存

2026-10-31，Richard（iPhone 12 Pro Max，iOS 18.7.8），**TrashVPN 1.0.0 (10012)**。协议为 WG、AWG、MASQUE H3，保持原应用身份、签名、图标和橘色主题。

## 已实现

| 当前协议状态 | 自动行为 |
| --- | --- |
| 未注册 | 本机生成密钥，注册并启用 Cloudflare 身份，然后优选 |
| 注册中断 | 使用已保存的身份继续登记步骤，不重复创建账号 |
| 已注册、无缓存 | 保留身份，自动优选 |
| 已注册、缓存到期 | 保留身份，自动优选 |
| 已注册、有效缓存 | 恢复节点，不注册、不优选、不续期 |
| 缓存损坏或与身份不匹配 | 视为无有效缓存，重新优选 |

检查由进入应用、回到前台和切换协议触发。已有 VPN 连接不会被自动切断，需要更新的流程在断开后继续。切换协议会取消并等待旧任务清理，旧任务回调不能覆盖新协议界面。

## 身份与缓存

- 三个协议使用独立身份，私钥和令牌保存到主程序与 VPN 扩展共享的钥匙串，设备首次解锁后可读取，不同步到其他设备。
- 注册分步保存；POST 成功即保存 ID 和令牌，后续 PATCH 失败可继续。MASQUE 对端必须是有效 P-256 密钥，不能把初始 WG 身份误判为 MASQUE 登记完成。
- 节点缓存按协议独立原子写入，绑定对应身份指纹；只有完整三次复测后有成功采样的节点才进入缓存。
- 到期时间为本轮完整优选成功时间加 **21600 秒**。查看、重开、切换协议、失败刷新和部分扫描均不延长到期时间。
- 缓存到期不会终止已经建立的 VPN。新建连接必须使用有效身份和缓存。
- 第一阶段测试私钥资源不再打包，生产流程不读取旧测试凭据。

## 优选

候选包括注册响应、旧缓存、公共端点提示和 Cloudflare 地址池抽样，最多 48 个。找到 4 个可用端点后进行每个三次的真实 HTTPS 复测，先比较成功率，再比较成功延迟中位数。端点逐个启动、测试和销毁，测试目标为 `https://cp.cloudflare.com/generate_204`。

整个优选流程不启动系统 VPN。退后台取消注册/优选任务并清理，注册检查点仍保留，回来后重新检查是否需要继续。

## 验证结果

**19 项逻辑与配置检查通过**，覆盖：

- 恰好 6 小时到期、命中不续期、到期优选不重新注册。
- 协议与身份隔离、缺失身份使旧缓存失效。
- 失败刷新不覆盖旧缓存、取消不把部分结果提升为有效缓存。
- 文件持久化及损坏后的重建。
- POST/PATCH 中断续接、MASQUE 密钥格式和错误对端保护。
- 真实 SDK 解析新生成的 WG/AWG/EC 密钥配置，以及前台接口拒绝创建 TUN。

首次真实注册运行的 **4 项真机流程全部通过**：

| 流程 | 结果 |
| --- | --- |
| WG 自动注册、优选、重开命中缓存、新身份连接 | `warp=on` |
| AWG 自动注册、优选、重开命中缓存、新身份连接 | `warp=on` |
| MASQUE 自动注册、优选、重开命中缓存、新身份连接 | `warp=on` |
| WG → AWG → MASQUE 切换，分别恢复有效缓存 | 通过，系统 VPN 保持关闭 |

测试没有点击注册或优选按钮来启动首次流程。最终回归中 WG 的一次出口验证超时；同一注册身份、同一缓存、相同到期时间下单次复测通过，未重新注册或优选。该次失败和复测结果均保留在 [机器可读记录](TestSummary.json)，未将失败结果包标记为全通过。

缓存时效表示何时需要重新测量，不保证节点在期间不会波动；可在断开后点击“重新优选”。
